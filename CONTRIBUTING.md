# Contributing

Open an issue or a focused pull request for a broken example, clearer documentation or a genuinely useful public-data workflow. Explain what changed and how you verified it.

Use public market reads only in demonstrations. Keep API credentials, private workspace content, copied job descriptions and personal information out of commits and issue reports. Preserve source URLs, timestamps, location classes and unknown values. Avoid automatic bulk requests and distinguish bounded search pages from complete snapshots.

Run the affected Python examples and all notebook code cells from the repository root. Examples need Python 3.10+ and curl. Respect service rate limits; external requests are not deterministic tests. Code contributions use the repository’s MIT License; it does not grant rights over third-party API data.
